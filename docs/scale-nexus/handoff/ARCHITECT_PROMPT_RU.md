## Workstreams and acceptance criteria
1. Каталог: извлеки все существующие записи карты и зафиксируй count. Аудит 100% записей: source+exact field+edition+massKind+radiusKind+epoch+frame+uncertainty+status+formulaId. Не теряй записи: неподходящие величины переносятся в отдельные слои с объяснением. Сверь Lineweaver–Patel и erratum. Обнови CODATA с версией; PDG/IAU/Planck/ESA/GRAVITY для соответствующих записей. Для нейтрино — предел и диапазон, не точное значение. Для галактик — явный радиус/апертура, массу привязать к области. Фотоны E/c² не rest mass; symmetries and bits are annotations. Не вычисляй density для несовместимых определений.
2. Математика: перенеси kernel.js в native formula registry, без дублирования. M-R <-> C-Q, inverse, Planck anchor and crossing, exact golden/base2/base10 relabeling, continuous N, optional grid only. Separate log values for numerical stability; handle nonfinite inputs, zero, overflow, uncertainty propagation with correlated constants. Add fixed M,R,density tracks and homogeneity dilation p; label regions as heuristic. Show selected object in both representations and preserve physical zoom/selection.
3. S³: import equations in RESEARCH_RU.md. Make distinct geodesic vs areal vs proper-volume-equivalent lengths, proper energy integral vs Misner–Sharp; full sphere/antipode cannot be placed as ordinary point. Both branches and complement test. Preserve published S³ reconstruction as separate model namespace. For FLRW require H, curvature, density and epoch consistent; never force model equivalence. Distinguish Hubble/apparent/particle/event horizons. Display explicit rho conventions and near/far branches. Link existing screens only after checking length definitions.
4. Nexus & laboratories: resolve actual IDs and map typed quantities. Add native route and machine-readable instrument with evaluateInstrument support, links to FBS3R, observable/cosmology, center lab, atomic/particle, compact objects/TOV/white dwarf, CMB and cosmic web where input semantics match. Test both directions; do not pass an energy-equivalent mass as rest mass. Integrate quantity bus, selection, Multiview, agent manifest, export and typed edge classes. No graph proximity as evidence. Add existing optical grammar and EN/DE/RU/JA translations, responsive touch/keyboard and XR parity using host infrastructure.
5. Lean: compile candidate in existing pinned mathlib environment; fix any errors without reducing theorem claims. Add exact SI-to-normalized bridge, positive-domain log product/quotient and inverse rpow for b>1, Planck square-root crossing, density lines, dilation covariance, actual S³ trig complement and volume derivative/integral (state hypotheses), flat limit, FLRW apparent horizon identity including curvature. Prove only algebraic/analytic implications, do not assert general relativity as formalized from scratch. `#print axioms` on every export; reject sorryAx/custom axioms/admit; publish source, toolchain pin, commit, build log and hash. Lean proof is not evidence for a physical model. Use independent exact rational/high precision fixtures to test JS/Lean mapping.
6. Research: implement preregistered golden-lattice test with complete selection model, family-block resampling, uncertainties and alternative base scan max statistic, holdout and null. No p-value for handpicked catalog. Publish negative/positive results alike; independent sample required. Compare prior art, including 1979/2023/2024 and interactive precedents. Draft manuscript on typed scale atlas and reproducible mathematics; separate hypotheses/results, no novelty inflation.
