# S³-Вселенная — интерактивная 3D-модель

Интерактивная трёхмерная модель **Солнечной системы** и **Вселенной как компактного
трёхсферного носителя S³_R**, построенная в точном соответствии со статьёй
*«Conditional Reconstruction of a Quasi-Local Observable Domain within Compact S³ Geometry»*
(Preece & Batenin, v38, «light sphere screens»).

## Запуск

Откройте `index.html` в любом современном браузере (нужен доступ в интернет для
загрузки Three.js с CDN). Локальный сервер не обязателен:

```bash
# вариант с сервером
python3 -m http.server 8000   # → http://localhost:8000
```

Управление: вращение — левая кнопка мыши, масштаб — колесо, панорама — правая кнопка.

## Три режима

### ☀ Солнечная система (1 ед. = 1 а.е.)
- 8 планет + Плутон на **точных кеплеровых орбитах** (элементы J2000 из
  приближённых эфемерид JPL: a, e, i, L, ϖ, Ω + вековые скорости средней долготы).
- Уравнение Кеплера `M = E − e·sinE` решается итерациями Ньютона; позиции —
  в гелиоцентрической эклиптике J2000.
- Управление временем (от суток/с до тысяч лет/с), привязка к реальной дате,
  пояс астероидов, кольца Сатурна.
- Режим **«истинный масштаб»**: размеры тел 1:1 к расстояниям — честная
  демонстрация локальной квазиевклидовой физики (U ⊂ S³_R, U ≃ ℝ³, §II статьи).

### ◯ Наблюдаемая Вселенная (1 ед. = 1 Gly)
Светосферные экраны наблюдателя из §«Invariant Light-Sphere Screens»:
- `ct₀ = 13.788 Gly` — световой возраст (статический диагностический масштаб);
- `S²_LSS ≈ 45.4 Gly` — экран последнего рассеяния (фоново-зависимый);
- `S²_ph = 46.125 Gly` — экран горизонта частиц, граница D_obs(p,T);
- кластеризованная крупномасштабная структура внутри шара B³_χ(p).

Экраны — **границы реконструкции, а не границы космоса**: ∂S³_R = ∅.

### ⬡ Глобальный носитель S³ (1 ед. = 100 Gly)
Точная визуализация компактной трёхсферы через её большое 2-сферное сечение
(содержит все геодезические через наблюдателя):
- сфера радиуса **R = 548.324513026856 Gly**, наблюдатель p и антипод −p
  (d = πR = 1722.6 Gly);
- **наблюдаемая Вселенная — шапка θ_particle = 4.82°**, объёмная доля
  Γ_obs = 0.0126 % (точная формула Γ(χ) = (χ − ½sin2χ)/π);
- интерактивный экран S²_χ с живым расчётом A(χ) = 4πR²sin²χ и Γ(χ):
  «граница без границы» — экран растёт до экватора и стягивается к антиподу;
- **фотон вдоль большой окружности** C = 2πR = 3445.2 Gly со счётчиком
  Γ(T) причинной доступности и отметкой t_coh = πR/c = 1722.6 Gyr;
- **расслоение Хопфа** S¹ ↪ S³ → S² в стереографической проекции
  (вложенные торы из окружностей Вилларсо) — встроенная топология носителя.

## Дисциплина модели (как в статье)

Визуализация воспроизводит и оговорки статьи: это **условная реконструкция**,
не детекция топологии; круглое S³ не задаёт выделенных направлений (SO(4));
t_R = 548.3 Gyr — не возраст Вселенной; горизонт частиц — фоново-зависимый
вход, а не теорема геометрии; квотиенты S³/Γ (додекаэдр Пуанкаре) — исключённый
сектор односвязного выбора Γ = {1}.
