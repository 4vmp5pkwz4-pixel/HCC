Calling it from code

// the whole computational core, with no renderer at all
await fetch('./api/manifest.json').then(r => r.json());   // static, no JS execution needed

// or drive the live atlas headless — ?render=0 skips the GPU entirely
await HCC_API.ready({ timeout: 10000 });   // rejects with code TIMEOUT rather than lying
HCC_API.health();                          // core, version, build, capabilities
HCC_API.labs.list();                       // every laboratory, with its capability class
HCC_API.instruments.list();                // the typed instruments
HCC_API.describe('anyon');                 // inputs, units, domain, limits, verifiers
HCC_API.evaluate('anyon', { n: 12, braid: '121' });   // the numbers
HCC_API.report('anyon', { n: 12, braid: '121' });     // numbers + provenance, as JSON
HCC_API.ui.unreachable();                  // controls outside the viewport, on this screen

Inputs outside a declared domain are refused, never clamped. Every laboratory route is a permanent link of the form #/world/<world>/lab/<id>.
