02 / COMPUTE

Вычислить и воспроизвести

Статический ESM SDK: поиск, описание, сценарии масштабирования и аудит прогнозов. Графический движок не требуется.

import { connectAtlas } from './api/agent-client.mjs';
const atlas = await connectAtlas('https://4vmp5pkwz4-pixel.github.io/HCC/');
atlas.search({ query: 'anyon' });
atlas.describe('anyon');
atlas.forecast('bht.M', 0.1);
const result = await atlas.audit(input);
Исходный код SDK ↗

В браузере импортируйте модуль по URL. В Node скачайте репозиторий и импортируйте локальный файл. Экспорт аудита содержит исходный JSON и SHA-256 для повтора расчёта.

03 / EXTEND

HTTP, MCP и полный Atlas

Для серверных расчётов запустите вычислительное ядро. Публичный GitHub Pages публикует файлы; серверные POST и MCP на нём не размещены.
