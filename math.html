ЯВНО ЗАДАННАЯ ГЕОМЕТРИЯ

Однозначность ≠ устойчивость.

Полоса скалярных гармоник 0 ≤ n ≤ L на круглой S³. Непрерывное ограничение на открытую геодезическую область χ. Это геометрический расчёт, а не наблюдение топологии Вселенной.

DERIVED / MODEL

Размерность полного скалярного пространства отличается от размерности радиального подпространства. Радиус R сокращается при одинаковой нормировке L²; χ = d / R.

Кривая: аналитическая нижняя граница ‖T⁻¹‖. Это оценка по явному пробному полю, а не вычисленный наименьший сингулярный показатель.

Радиальная матрица ограничения

Gₙₘ = π⁻¹[sin((n−m)χ)/(n−m) − sin((n+m+2)χ)/(n+m+2)]. При n = m первый член равен χ. Матрица покрывает L+1 радиальных мод; полный скалярный набор содержит Σ(n+1)² мод.

Проверяемое следствие

fL(θ) = (1 − cos θ)L

rL = Isin²(χ/2)(2L + 3/2, 3/2)

‖T⁻¹‖ ≥ rL−1/2

κ(T) ≥ √(Vcap / rL)

При χ → 0: rL ∼ CLχ4L+3. Инъективность конечной полосы следует из аналитичности; её практическая устойчивость зависит от области и ошибок измерения.
