# FibonacciTopoNet v3 — воспроизводимый исследовательский прототип

**16 октября 2026** · Python 3.10+ · PyTorch (CPU/GPU) · исходная линия: `FibonacciTopoNet v2`.

## Что реально создано

Маленькая (7 605 параметров в измеренной конфигурации) последовательностная модель с:

1. **Строго причинным многомасштабным локальным вниманием:** окна `[1,2,3,5,8]`, выбор масштаба обучаем, память активаций внимания растёт по длине как `O(TW)`, а не `O(T²)`. Это реализация на `unfold`, **не** FlashAttention.
2. **Глобальной селективной памятью:** ограниченная по норме диагонально-гейтированная рекурсия с базисом из нормированных companion-блоков Фибоначчи. Обновление идёт по токенам, не является реализацией Mamba-2/Titans.
3. **Явно заданными симметриями:** `OrbitAveraging` для реверса (`Z2`) либо циклической группы (`Z_T`). Применять *только*, если правильный ответ инвариантен к указанной группе.
4. **Спектральной регуляризацией представлений:** штраф на разброс собственных значений центрированной ковариации, не утверждает вычисление гомологий или топологическую защиту памяти.
5. **Математической проверкой остаточной идентифицируемости:** `profiled_gaussian_fisher` вычисляет расстояние контраста до линейного пространства мешающих параметров в метрике гауссовской информации.

## Пример использования

```python
import torch
from fibonacci_topo_net_v3 import FibTopoNetV3, OrbitAveraging

net = FibTopoNetV3(vocab_size=1000, d_model=32, layers=2,
                   heads=4, scales=(1, 2, 3, 5, 8),
                   num_classes=3, use_memory=True)
tokens = torch.randint(1, 1000, (4, 48))
logits, penalty = net(tokens, return_reg=True)
loss = torch.nn.functional.cross_entropy(logits,
                torch.randint(0, 3, (4,))) + penalty
loss.backward()

# Только для задач, в которых разворот входа НЕ меняет целевой класс:
symmetric_net = OrbitAveraging(net.eval(), group='reversal')
with torch.no_grad():
    invariant_logits = symmetric_net(tokens)
```

Специальный токен `0` означает правый padding. `valid` можно подавать вручную; валидные токены должны образовывать непрерывный префикс. `return_tokens=True` выдаёт причинные предсказания для каждого положения. Демо-чекпойнт обучен **только** синтетической бинарной задаче; это не языковая модель, которая умеет вести диалог.

## Контрольный эксперимент

Задача: по токену на позиции 0 предсказать бинарный класс в конце последовательности. Промежуточные токены независимы от метки. Обучение: длина 48, 2048 примеров, AdamW, 180 шагов, batch=64; 512 валидационных и 512 тестовых примеров. Два seed: 19 и 29. Перенос на длины 96 и 192 без дообучения.

| Вариант | T=48 (два seed) | T=96 | T=192 |
|---|---:|---:|---:|
| Fibonacci + память | 100%, 100% | 100%, 100% | 100%, 78.91% |
| Fibonacci, без памяти | 50.20%, 47.66% | 49.41%, 51.76% | 50.20%, 50.78% |
| Контрольные окна (1,2,4,6,8) + память | 100%, 100% | 100%, 100% | 100%, 78.32% |

Обучение и первичная проверка проведены на CPU PyTorch 2.10.0. Сравнение с нефибоначчиевой схемой использует одинаковые параметрические формы (7 605 параметров). В абляции «без памяти» модуль памяти выделен, но отключён, поэтому активных параметров меньше. Это диагностический контроль, не строгий параметрический матч.

**Вывод:** введённый канал памяти научился задаче дальнего контекста, недоступной последнему токену ограниченной локальной модели; преимуществ особой последовательности Фибоначчи не обнаружено. Снижение качества при T=192 для одного seed показывает отсутствие универсальной гарантии генерализации по длине.

## Теоретические обязательства

- Доказуемая причинность без памяти: при `L` слоях и радиусе локального внимания `W`, выход токена `t` не зависит от входов ранее `t-LW`.
- Конечная групповая проекция: `P_G f(x)=|G|^{-1}∑_{g∈G} f(gx)` идемпотентна и инвариантна для полного конечного действия при детерминированном `f`.
- Селективная память: `h_t=a_t⊙h_{t-1}+(1-a_t)⊙u_t`, `0<a_t<0.995`, `|u_t|≤1`. При `h_0=0` получаем `|h_t|≤1` покомпонентно и `∥∂h_t/∂h_{t-1}∥₂ ≤0.995` при фиксированном входе.
- Нормированная матрица `[[1,1],[1,0]]/φ` имеет собственные числа `1` и `−φ⁻²`, следовательно её спектральная норма равна 1.
- Фишер после nuisance: `F_{D|B}=½ min_a ‖C^{-1/2}(D−∑ a_jB_j)C^{-1/2}‖_F²`.

## Научные ограничения

- Это **не фундаментальный закон физики**, не доказательство преимуществ золотого сечения и не S³-геометрическая модель; используются общие принципы операторных проекторов, устойчивости и идентифицируемости, разработанные также в монографии.
- Модель не обучена на естественных языках, коде, физике или решении новых теорем; отсутствуют реальные бенчмарки LLM, сравнительные прогоны с Mamba/Transformer/Titans и оценки энергопотребления.
- Рекурсия написана как последовательный цикл Python: асимптотически линейная, но **не** высокопроизводительная параллельная GPU-реализация.
- Для переменных задач и распределений потребуются оценка распределительного сдвига, независимая калибровка, множество seed, проверка чувствительности и воспроизводимые большие датасеты.
