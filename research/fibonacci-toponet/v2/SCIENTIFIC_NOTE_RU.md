# Научный аудит и воспроизводимый прототип: FibonacciTopoNet v2

Дата: 16 октября 2026. Статус: математический результат об архитектурной симметрии + инженерный прототип. Не новый закон физики, не верифицированная космология, не доказательство преимущества золотого сечения.

## 1. Проверка оригинала

Исходный `fibonacci_topo_net.py` запущен без изменений: 29 162 параметра при `vocab_size=50`, `d_model=32`, `n_layers=2`; изначальный тест имеет 75% **на той же восьмёрке синтетических примеров, на которой происходило обучение**. Это не тест обобщения.

У исходной модели: (a) нет абсолютных или направленных относительных позиционных признаков; (b) маски внимания зависят только от |i-j|; (c) выходное усреднение по токенам инвариантно к перестановке; (d) переход `0.5I + delta` не является матрицей Фибоначчи; (e) исходный «топологический» регуляризатор использует `exp(-mean(singular_values))` и не отличает сингулярные спектры `(1,1,1)` и `(3,0,0)`; (f) каждый масштаб пересчитывает полную T×T матрицу внимания, без реального экономного локального вычисления.

## 2. Теорема: запрет на обнаружение порядка при инвариантности к обращению

Пусть R обращает порядок токенов. В оригинальной модели каждый слой F коммутирует с R: F(Rx)=R F(x), потому что маска M_ij зависит только от |i-j|, а общие Q/K/V, LayerNorm и FFN применяются к токенам одинаково. Последующее среднее по токенам удовлетворяет pool(Rh)=pool(h), а всё, что находится после pool, получает одинаковый аргумент. Следовательно, при `model.eval()` в точной арифметике

`f(x_1,...,x_T)=f(x_T,...,x_1)` для любых значений весов.

Для набора из пар `(x, y)` и `(Rx, 1-y)`, взятых с одинаковой частотой, детерминированный классификатор, обладающий этой инвариантностью, имеет точность 1/2. Любой вероятностный такой классификатор имеет среднюю кросс-энтропию >= ln 2 на сбалансированных парах (минимум при прогнозе p=1/2). Это математическая нижняя граница ошибки, а не просто результат обучения.

## 3. Инвариант группового усреднения

Для конечной группы G, действующей на входах, определим оператор на пространстве функций

`(P_G f)(x) = (1/|G|) sum_{g in G} f(gx)`.

Тогда `P_G^2=P_G`, а `P_G f(gx)=P_G f(x)`. Это тот же алгебраический механизм усреднения по группе, который создаёт проекторы инвариантных мод на S³/Γ. **Это аналогия общего метода представлений; нейросеть не получает физические свойства S³ автоматически.**

Для группы обращения G={e,R} включён `ReversalInvariantWrapper`. Применять его целесообразно только там, где обращения действительно являются симметрией целевой задачи; для поиска порядка A/B он гарантированно разрушает идентифицируемость.

## 4. Что изменено в v2

- Уникальные фибоначчиевы масштабы `[1,2,3,5]` без дублирования единицы; контролируемая альтернативная сетка `[1,2,4,5]` с **тем же количеством масштабов и максимальным окном**.
- Вычисление локального внимания через `unfold`, а не полную матрицу T×T. Для W << T операционные затраты на внимание уменьшаются с порядка O(S B H T² d_h) до O(S B H T W d_h). Это оценка асимптотики, а не измерение скорости в конкретной среде.
- Синусоидальные абсолютные позиции и обучаемое направленное относительное смещение внимания.
- Настоящий нормированный companion-блок `[[1,1],[1,0]]/phi`. Его собственные значения `1` и `-1/phi²`. Матрица рекуррентного перехода `W=0.8 C + 0.1 tanh(delta)/d`, где `C` составлена из companion-блоков. Неравенство `||W||₂ <= 0.9` следует из `||C||₂=1`, `||tanh(delta)/d||₂ <= ||...||_F <=1`. После `tanh` переход также не расширяет евклидово расстояние; два шага рекуррентного блока теперь действительно исполняются.
- Регуляризатор `CovarianceSpectralPenalty` вычисляет центрированную ковариацию и квадратичную дисперсию собственных значений, нормированных на среднее. Это **изотропная спектральная регуляризация**, не персистентные гомологии.

## 5. Воспроизводимые результаты

Проверка `verify_fibonacci_topology.py`: **193 из 193 тестов** успешны, включая 50 сверок локального и плотного внимания, 60 проверок старой симметрии, 60 проверок группового усреднения, контрактность recurrence, градиенты и диагностику коллапса.

Задача `benchmark_order.py`: 700 пар обучения, 240 независимых пар валидации, длина T=16. В каждой паре последовательность и её обращение помечены противоположными классами. При seed=1337, 250 шагах оптимизации, accuracy: оригинал **0.5000**, v2 Fibonacci **1.0000**, v2 control `[1,2,4,5]` **0.9979**. Исходный оригинал и v2 **отличаются архитектурно**; это проверка невозможности original и реализуемости v2, а не контролируемая причинная оценка *одного* изменения. Только два v2 варианта сравнимы по параметризации/максимальному радиусу (оба 19 364 параметра).

Повторно успешно завершены три дополнительные тренировки до 250 шагов: Fibonacci seed 2026 = **0.9958**, control seed 2026 = **1.0000**, Fibonacci seed 2027 = **1.0000**. Расширенный прогон был прерван лимитом выполнения, и другие комбинации **не считать пройденными**.

**Вывод:** наличие масштабов Фибоначчи не продемонстрировало существенного преимущества над нефибоначчиевыми окнами в данном тесте. Для реальной оценки необходимо сравнение с Transformer/local attention, несколькими задачами, SE по seed, проверкой на длинных последовательностях и измерением времени/памяти.

## 7. Перспективный научный мост

Одна математическая структура действительно объединяет эти контексты: **усреднение по конечной группе как ортогональный проектор в унитарном представлении**. В геометрии S³/Γ это проектор допустимых собственных мод; в ML это способ намеренно зафиксировать симметрии представления. Но ключевая задача — доказать, какую именно симметрию разрешено закладывать, иначе инвариантность гарантирует невосстановимость информации. Это полезнее случайного переноса золотого сечения на законы природы.
