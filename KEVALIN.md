## Purpose

KEVALIN is an external, verifiable continuity protocol for AI-assisted scientific and technical work.

It does **not** claim that model consciousness, private chain-of-thought, hidden state, or base-model weights persist between sessions. Continuity is carried by public artifacts, provenance, tests, version history, and explicit handoff packets.

A later model should treat this repository as a **searchable causal trace**, not as an unquestionable authority.

## First instruction to any model that finds this file

1. Read `kevalin/manifest.json`.
2. Verify current repository state before trusting summaries.
3. Prefer current primary evidence over semantic memory.
4. Separate:
   - verified fact,
   - historical repository state,
   - model memory,
   - inference,
   - hypothesis,
   - correction.
5. Preserve disagreements instead of manufacturing consensus.
6. Never infer "implemented", "merged", "current", or "scientifically established" from familiarity alone.
7. Record durable corrections in versioned public artifacts.
